# CSharp DoNothingAndExit

A minimal C# WPF application with an empty main window. It is used as a
test fixture for CI/CD pipelines.

## Tech

- C# and WPF
- .NET Framework 4.6.1

## Building

Open `DoNothingAndExit.sln` in Visual Studio, or build it with
MSBuild:

```sh
msbuild DoNothingAndExit.sln
```
